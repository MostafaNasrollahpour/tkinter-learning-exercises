# Tkinter Learning Exercises

A collection of Python Tkinter exercises created while learning GUI development with Python.

This repository contains a series of small, focused examples covering the fundamentals of Tkinter, progressing from basic windows and widgets to events, canvas operations, drag and drop, and simple animations.

## Project History

These exercises were originally created in **February 2025**, during an earlier stage of my Python learning journey.

The code reflects my understanding and coding style at that time and is intentionally preserved mostly as it was. It should be viewed as a record of my learning progress rather than as an example of my current coding style or production-level Python development.

Some minor repository maintenance and documentation updates may have been made later, but the exercises themselves belong to that earlier learning period.

## Learning Path

The exercises are intended to be studied progressively.

See [`map.txt`](./map.txt) for the recommended learning sequence.

The learning path starts with basic Tkinter concepts such as windows, labels, and buttons, and gradually moves toward more interactive examples involving events, canvas elements, image movement, and animations.

## Running the Examples

You need **Python 3** with Tkinter available.

Clone the repository:

```bash
git clone https://github.com/MostafaNasrollahpour/tkinter-learning-exercises.git
cd tkinter-learning-exercises/tutorial
```

Then run any example:

```bash
python window.py
```

Depending on your system, you may need to use:

```bash
python3 window.py
```

Some examples use image files from the `tutorial/images` directory, so running them from inside the `tutorial` directory is recommended.
