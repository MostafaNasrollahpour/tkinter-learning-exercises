# Tkinter Learning Exercises

A collection of Python Tkinter exercises created while learning GUI development with Python.

The repository covers core Tkinter concepts through a series of small, focused examples. The exercises are intended to be studied progressively, from basic windows and widgets to events, canvas operations, drag and drop, and simple animations.

## Learning Path

The exercises are designed to be read in a specific order.

See [`map.txt`](./map.txt) for the recommended learning sequence.

## Topics Covered

- Windows and labels
- Buttons and user input
- Checkboxes and radio buttons
- Scales and listboxes
- Message boxes and color chooser
- Text areas and file dialogs
- Menus and frames
- Multiple windows and tabs
- Grid layout
- Progress bars
- Canvas
- Keyboard and mouse events
- Drag and drop
- Image movement
- Basic animations

## Learning Source

These exercises were created while following the Tkinter tutorials by **Bro Code** on YouTube.

This repository is preserved as a record of my learning process and as a reference for basic Tkinter concepts.
